# Security Policy

## Reporting a vulnerability

Report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/nao1215/geokit/security/advisories/new), or by email to [n.chika156@gmail.com](mailto:n.chika156@gmail.com). Please do not open a public issue for it.

Include the affected version, how to reproduce it, and what an attacker can do with it. You will get a reply within a week. Once a fix is released, the advisory is published and credits the reporter unless they ask not to be named.

## Supported versions

Only the latest release on [Hex](https://hex.pm/packages/geokit) receives security fixes. Fixes are released as a new version; older versions are not patched.
